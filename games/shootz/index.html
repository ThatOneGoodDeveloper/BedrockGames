Shootz Unblocked — game guide

Shootz is a shooting game in our browser catalogue. The focus is aiming, positioning and target priority. These games are usually wave-based or score-based, so a short run is enough to learn the pace.

Shooting games reward patience. Line up the shot before you commit, keep moving between shots, and do not chase a target into a worse position. If the external host is blocked, our local Space Invaders and Asteroids fallbacks are available.

How to play Shootz

  1. Press Play and click the frame once to focus it.
  2. Aim with the mouse or arrow keys, depending on the game.
  3. Fire with the left mouse button, Space, or the control shown in-game.
  4. Use fullscreen for a larger view of the target area.
