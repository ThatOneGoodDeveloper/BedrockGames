# Bedrock Games

A collection of 806 browser games, presented like a game console home screen in the style of the PlayStation 5: a deep blue backdrop, a row of big game tiles, a white focus ring that grows the selected tile, the game's art glowing behind it, and a clock in the corner. All artwork and icons are original. No accounts, and no analytics or tracking scripts on this site's own pages.

**Live site:** https://thatonegooddeveloper.github.io/BedrockGames/

## What's in it

- **Games.** One scrolling shelf of tiles (or **Grid view** for the whole library at once). Category chips (All Games, Favorites, Recently Played and 10 categories), a filter field, and sorting. Select a tile and its name and **Play** / **Save** buttons appear below. Playing opens the game fullscreen right away; press `Esc` to leave.
- **Apps.** Four web pages that open inside the site, each in its own full-screen page with a back button.
- **Search.** Press `/` or `Ctrl`/`Cmd` + `K` to search games and apps from anywhere.
- **Settings.** Background, accent color, auto fullscreen, a backup file, and the disguise tools below.
- **Disguise tools.** Open the site inside an `about:blank` tab, set a custom tab title and icon (Google, Drive, Docs, Classroom, Canvas, Wikipedia, Khan Academy), and a panic key (default `` ` ``) that jumps to a page you choose.
- **Open in about:blank.** The menu on the logo button, the Settings button, or the game player's **Tab** button. Allow pop-ups for the site first. When the site is opened from a downloaded file, the about:blank tab loads the hosted copy, so it needs an internet connection (a built-in game opened with the Tab button works offline).
- **Controller and keyboard.** Arrow keys move around. With a controller, the D-pad or left stick moves, Cross selects and Circle goes back.
- **Works on phones.** The shelf becomes a grid and the layout fits the screen.

### Keyboard shortcuts

| Key | Action |
| --- | --- |
| Arrow keys | Move between tiles and controls |
| `Enter` | Open the selected tile |
| `/` or `Ctrl`/`Cmd` + `K` | Search |
| `1` `2` `3` | Open Games, Apps, Settings |
| `?` | Open Help |
| `Esc` | Close search, a menu or page, or leave the current game |
| `` ` `` (changeable) | Panic key: jump to your panic page |

## Where the games come from

- **26 built-in games** (Snake, Tetris, 2048, Chess, Pac-Man and others) are stored inside the site file itself and run without an internet connection.
- **780 other games** load from their original host (`inkyedu118.github.io`). They need an internet connection, and they stop working if that host is blocked or goes away.

Game names, artwork and content belong to their respective owners. Games that load from another host are served by that host, so their pages may have their own ads or tracking.

## Two files, everything inside

The whole site, with the code, styles, thumbnails and the built-in games, is in each of these files. There is no iframe of a website and nothing else to download:

- **`index.html`**: open it in any browser, or put it on any static host.
- **`bedrock.svg`**: the same site as an SVG image file. Open it in its own tab. The page is real HTML inside the SVG, not a frame pointing at a web address.

Both work from a downloaded file (double-click) and on GitHub Pages, S3, Netlify and so on.

## Your data

Favorites, history, play counts and options are stored in your browser only. **Options > Backup** exports them to a file you can load on another device. The site itself sends nothing to any server. Games that load from another host, and the tab icons you can choose in Options (loaded from Google, Wikipedia and similar), contact those hosts when used.

## Building the two files

`index.html` and `bedrock.svg` are generated. Edit the sources in `src/` and run (Python 3, nothing to install):

```sh
python3 src/build.py
```

| Path | What it is |
| --- | --- |
| `index.html`, `bedrock.svg` | The finished site, generated by the build |
| `src/app/` | The home screen: `template.html`, `site.css`, `site.js` and `data.js` (the game list) |
| `src/game/` | Sources of the built-in games, their shared styles and scripts, and card images |
| `src/thumbs/` | One small thumbnail per game |
| `src/build.py` | Puts it all together |
