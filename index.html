Set up a Wisp server

The proxy needs a Wisp server, a small program that relays connections. GitHub Pages cannot run one, but you do not need to run it on your computer.

1. Free hosting on Render: sign in at render.com, choose New, then Blueprint, pick this GitHub repo, and deploy. It reads render.yaml for you. When it is live, paste wss://YOUR-NAME.onrender.com/wisp/ into the Wisp server box above and press Test. The free plan sleeps when idle, so the first load after a break can take about a minute.

2. Any other Node host works too. Start it with npm install and npm start, set HOST to 0.0.0.0, and set ALLOWED_ORIGINS to your site address so strangers cannot use it.

3. On your own computer: run npm install then npm start and open http://localhost:8080.
